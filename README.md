# EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:
## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
## PROCEDURE:
1. Open a new file in Fusion 360 and select Create Sketch. Select the Front (XZ) Plane as the sketching plane.
2. Select Rectangle → Center Rectangle and draw a rectangle at the centre with a width of 120 mm and a height of 60 mm.
3. Use the Arc command to draw the upper curved portion around the rectangle with a radius of R110 mm and an overall model height of 110 mm.

![image](https://user-images.githubusercontent.com/113594316/198823371-bacc7928-28aa-45dd-a652-8833f95e3ea9.png)

4. Draw horizontal lines on both sides of the rectangle to form the base portion with an overall length of 420 mm.
5. Draw the rounded end portions using arcs of radius R60 mm and complete the outer profile with the required dimensions

![image](https://user-images.githubusercontent.com/113594316/198823384-c72c4c0f-9650-48db-b7da-697a0f22886b.png)

6. Click Finish Sketch and use the Extrude command to give the model a width of 150 mm.
7. Create a new sketch on the top surface and draw two circles of diameter Ø40 mm, keeping the distance between their centres as 300 mm.


![image](https://user-images.githubusercontent.com/113594316/198823390-0832a221-257e-439f-99b4-1a8beca74b56.png)

8. Draw a centre circle of diameter Ø20 mm at the middle position, keeping it 150 mm from each side-hole centre.


![image](https://user-images.githubusercontent.com/113594316/198823401-1b79c82e-7665-4874-8135-52cbce3bb50d.png)

9. Use the Trim command to remove unwanted portions and apply the necessary constraints to complete the sketch.


![image](https://user-images.githubusercontent.com/113594316/198823408-d3d678f1-2247-41a2-abdd-b9a8918daef8.png)

10. Use the Extrude Cut command to create the required holes and openings. Maintain the base thickness of 30 mm.
11. Use Inspect → Measure to check all the dimensions, including 420 mm, 300 mm, 150 mm, 120 mm, 110 mm, 60 mm, R110 mm, R60 mm, Ø40 mm and Ø20 mm.

![image](https://user-images.githubusercontent.com/113594316/198823415-9d0a9454-b197-44bf-b90f-179c75602500.png)
12. Finally, switch to Drawing → From Design, create the drawing sheet according to ISO standards, place the Front, Top and Side views, add dimensions and save the final output.
